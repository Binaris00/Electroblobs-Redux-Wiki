  Frost Axe

_This page is about the item. For the spell, see [Frost Axe](/main/spell/frost_axe)._

Frozen axe that can inflict [Frostbite](/main/mob_effect/frostbite) when damaging targets.

It has the same stats as an iron tier tool.

## Obtaining

Frost Axe can only be temporarily obtained by using the spell [Frost Axe](/main/spell/frost_axe), making it a temporal item that the user has for a short period of time.
