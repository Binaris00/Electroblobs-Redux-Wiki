# Spectral dust

<img src="/resources/img/item/dusts.png" class="full-mc-icon"/>

Spectral dust are the residual magic essence of an element, they can be used to create new forms of magic or to be used as a fuel in most magic recipes.

## Obtaining

Spectral dust can be obtained only by killing [remnants](/main/entity/remnant) which are only found in [obelisks](/main/structure/obelisk).

To obtain a specific spectral dust element, you need to first find the obelisk of that element. (e.g. if you want to fire spectral dust you need to find an obelisk with the fire element and then kill those remnants)

## Usage

Right-clicking whilst holding a spectral dust inside a [receptacle](/main/block/receptacle) block automatically consumes it and makes the receptacle hold that spectral dust for you, generating a nice form of light. If you want the spectral dust back, just right-click on the receptacle again. This mechanic with the receptacle could be used with the [imbuement altar](/main/block/imbuement_altar) to craft new magical recipes using the spectral dust as a fuel.
