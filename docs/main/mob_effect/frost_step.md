This page is about the status effect. For the spell, see [Frost Step](/main/spell/frost_step)._

## Description

Frost Step is a beneficial potion effect that's the next level of the Frost Walk enchantment, this can freeze water and lave to frosted ice and obsidian crust, respectively. This gives the ability to walk to any liquid source.

## Sources

Being a powerful effect, this is only used in the Frost Step spell, giving Frost Step I for 30 seconds. The only other source of the effect is via commands.
