_This page is about the status effect. For the spell, see [Oakflesh](/main/spell/oakflesh)._

## Description

Oakflesh is a beneficial potion effect that slightly increases the user's vitality and damage resistance for the given time. This effect also gives a more 'natural' look to his user.

## Sources

The Oakflesh spell is the only source to obtain this normally, giving Oakflesh I for 30 seconds.
