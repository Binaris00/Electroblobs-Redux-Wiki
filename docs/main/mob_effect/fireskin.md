## Description

Fireskin is a beneficial status effect which causes players and mobs to set fire to attackers. A player or mob with the fire skin effect causes any creature that melee attacks it to be set on fire for 5 seconds.

## Sources

The fire skin spell grants the caster fire skin I for 30 seconds. The only other source of the effect is via commands.

## Trivia

- The amplifier has no effect for fire skin, much like fire resistance or water breathing in vanilla _Minecraft_.
